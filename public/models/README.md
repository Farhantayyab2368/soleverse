# 3D models

`shoe.glb` — "Materials Variants Shoe" by Shopify (Khronos glTF Sample Assets), licensed CC BY 4.0.
Attribution is shown in the site footer; keep it if you keep this model.

Replace it with any binary glTF sneaker to change the model site-wide. The file is validated on load; if it is
missing or invalid, the procedural SOLEVERSE sneaker is used instead.

Recolouring assumes a texture with a saturated upper, a white sole and dark laces. If your model's toe points
the other way, set `FLIP_TOE` in `src/three/realShoe.js`.
